## Issue 2: Schema -- single event, minimal table, delete legacy events — DONE

**Date:** 2026-03-27

### What was done

1. Deleted all 5 legacy event definitions from `schema.ts`: `layoutSplit`, `layoutPaneClosed`, `layoutPaneAssigned`, `layoutRestored`, `layoutWorkspacesReordered`.
2. Deleted all 13 hierarchical event definitions from `schema.ts`: `windowTabCreated`, `windowTabClosed`, `windowTabSwitched`, `windowTabRenamed`, `windowTabsReordered`, `panelTabCreated`, `panelTabClosed`, `panelTabSwitched`, `panelTabsReordered`, `windowLayoutRestored`, `windowLayoutSplit`, `windowLayoutPaneClosed`, `windowLayoutPaneAssigned`.
3. Deleted the intermediate schema types `layoutEventSchema` and `windowLayoutEventSchema`.
4. Deleted all 18 no-op materializers for the removed events.
5. Removed all 18 deleted events from the `events` export object.
6. Removed the `PanelNodeSchema` import from `schema.ts` (no longer needed).
7. The single `windowLayoutUpdated` event (already defined) is now the sole layout event. The `panelLayout` table already had only `windowId` and `windowLayout` columns.
8. Updated all ~30 commit sites in `use-panel-layout.ts` to use `windowLayoutUpdated` with descriptive `reason` strings instead of the old events.
9. Replaced the `commitWindowLayout` helper (which accepted an event constructor) with a version that accepts a `reason` string.
10. Replaced the `commitPanelTabLayout` helper similarly.
11. Combined dual-write patterns (legacy event + hierarchical event) into single `windowLayoutUpdated` commits.
12. Combined focus-restoration commits (window/panel tab switch + `layoutPaneAssigned`) into single commits using `saveFocusedPaneId`.
13. Extracted `commitDevServerUpdate` helper to reduce complexity in `handleToggleDevServerPane` (below lint threshold of 20).
14. Updated `schema.test.ts`: removed tests for legacy events and old hierarchical events (they no longer exist). The 6 existing `windowLayoutUpdated` tests remain and pass.
15. Updated `use-panel-layout.test.ts`: replaced all individual event mocks with a single `windowLayoutUpdatedMock`. Converted 13 tests that relied on old event payloads to `it.todo()` — these need to be rewritten with `WindowLayout` fixtures in Issues 7/9.
16. `bun run check` passes (typecheck + format + all tests across all packages).

### Files changed

- `packages/shared/src/schema.ts` — Deleted 18 events, their schemas, no-op materializers, and exports
- `packages/shared/test/schema.test.ts` — Removed legacy event and old hierarchical event tests
- `apps/web/src/routes/-hooks/use-panel-layout.ts` — Converted all ~30 commit sites to `windowLayoutUpdated`, updated helpers, extracted `commitDevServerUpdate`
- `apps/web/test/use-panel-layout.test.ts` — Replaced event mocks with `windowLayoutUpdatedMock`, converted 13 tests to `it.todo()`
